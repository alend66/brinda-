## ⚡ Highlights & Architecture

- **Strictly in English:** 100% of the UI, telemetry, terminal commands, and documentation are in English.
- **Anime Cyberpunk Aesthetic:** Glowing neon HUD styling (cyan, magenta, electric purple, and matrix emerald), dynamic particle canvas, and toggleable CRT scanlines.
- **Audio Feedback Synthesizer:** Real-time Web Audio API synthesized futuristic sound effects with instant mute/unmute control.
- **Interactive SOC Telemetry & Radar:** Real-time sweeping radar canvas with simulated security incidents and interactive triage actions.
- **Interactive Mission Simulators:**
  - **Splunk Enterprise SIEM:** Live SPL query simulator (SSH brute force, port scan reconnaissance, C2 beaconing, data exfiltration).
  - **Nmap Network Recon:** Interactive command-line simulator (SYN stealth scans, version probes, NSE vulnerability checks).
- **BRINDA-OS Interactive Terminal:** Functional terminal console supporting `help`, `whoami`, `skills`, `projects`, `forensics`, `scan`, `education`, `contact`, and `clear`.
- **Dossier CV Modal:** One-click modal reproducing the full resume with printable / Save as PDF support.
- **Direct Gmail Dispatch Transmission:** Contact form directly connected to Brinda's Gmail (`brindababu2435@gmail.com`) with instant Gmail Web compose integration.

## 🚀 How to Run Locally

### Option 1: Native Node.js Server
```bash
node server.js
```
Then navigate to `http://localhost:8089` in your browser.

### Option 2: Any Static Server / Python
```bash
npx serve .
# or
python -m http.server 8080
```
Or simply double-click `index.html` to open directly in any modern browser!
